  9    Base class for KDC software Agents.
 10
 11    An Agent encapsulates data and identifies programming logic to be
 12    executed by a receiving application through a registered API.
 13
 14    KDC transmits an Agent's serialized state across the network.
 15    The receiving application must have a compatible Agent class
 16    available to reconstruct and process the Agent.
 17
 18    This Python implementation is designed to maintain compatibility
 19    with the KDC-Java Agent serialization contract.
 20
 21    Transport, connection management, and reply handling are managed
 22    separately from this class.
 23
 24    Attributes:
 25        uuid (uuid.UUID):
 26            Unique identifier assigned when the Agent is created.
 27
 28        visitor_method_name (str | None):
 29            Name of the API visitor method associated with this Agent.
 30
 31        api_class_name (str | None):
 32            Name of the API class containing the visitor method.
 33
 34        creation_time_stamp (int):
 35            Agent creation timestamp. Defaults to 0.
 36
 37        size_in_bytes (int):
 38            Serialized Agent size in bytes. Defaults to 0.
 39
 40        synchronous (bool):
 41            Indicates whether the Agent is associated with a
 42            synchronous operation. Defaults to False.
 43
 44        data (dict | None):
 45            Dictionary containing application-defined Agent data.
 46
 47        latency_record (LatencyRecord | None):
 48            Optional record containing latency measurements.
