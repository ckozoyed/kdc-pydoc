 12class ParametersBuilder:
 13    """
 14    Builder for configuring KDC framework parameters.
 15
 16    ParametersBuilder provides a fluent interface for
 17    configuring common KDC communication settings.
 18
 19    Configuration includes:
 20        - Client startup and network binding.
 21        - Protocol version and receive buffer size.
 22        - Compression and encryption.
 23        - CRC integrity checking.
 24        - Python-to-Java field name translation.
 25        - Serialization security white lists.
 26        - Agent class registration.
 27        - Serialization diagnostics.
 28
 29    Settings not explicitly configured use the defaults
 30    defined by Parameters.
 31
 32    Builder methods return the builder instance, allowing
 33    multiple configuration options to be chained.
 34
 35    Example:
 36        Configure common KDC settings::
 37
 38            builder = (
 39                ParametersBuilder()
 40                .with_auto_start(True)
 41                .with_compression(True)
 42                .with_crc(True)
 43                .with_case_translation(True)
 44            )
 45
 46            parameters = builder.build()
 47
 48    Note:
 49        Transport-specific parameter builders extend
 50        this class with additional configuration options.
 51    """
 52
 53    def __init__(self):
 54        """
 55        Initialize a parameter builder.
 56
 57        Scalar configuration fields are initialized to
 58        None, indicating that the corresponding default
 59        from Parameters should be used.
 60
 61        A new white list and AgentRegistry are created
 62        for each builder instance.
 63        """
 64
 65        #
 66        # None means "use the default defined by Parameters"
 67        #
 68        self.protocol_version = None
 69        self.auto_start = None
 70        self.bind_address = None
 71        self.max_received_buffer_size = None
 72
 73        self.compression = None
 74        self.encryption_key = None
 75        self.crc_check = None
 76
 77        #
 78        # Mutable objects still receive fresh instances.
 79        #
 80        self.white_list = set()
 81        self.agent_registry = AgentRegistry()
 82
 83        self.trace_serialization = None
 84        self.case_translation = None

134    def with_bind_address(self, host: str, port: int):
135        """
136        Configure the local network bind address.
137
138        Args:
139            host (str):
140                Local hostname or IP address.
141            port (int):
142                Local port number, from 0 through 65535.
143                Port zero requests an automatically
144                assigned port.
145
146        Returns:
147            ParametersBuilder:
148                This builder for method chaining.
149
150        Raises:
151            ValueError:
152                If the host is empty or the port is invalid.
153        """
154        if not isinstance(host, str) or not host.strip():
155            raise ValueError("host must be a non-empty string")
156
157        if not isinstance(port, int) or not (0 <= port <= 65535):
158            raise ValueError("port must be in range 0-65535")
159
160        self.bind_address = (host.strip(), port)
161        return self

348    def with_white_list(self, white_list):
349        """
350        Replace the serialization white list.
351
352        Entries are normalized by removing surrounding
353        whitespace and stored as a set.
354
355        Args:
356            white_list (set | list | tuple):
357                Collection of permitted class names.
358
359        Returns:
360            ParametersBuilder:
361                This builder for method chaining.
362
363        Raises:
364            TypeError:
365                If white_list is not a set, list, or tuple.
366            ValueError:
367                If any entry is empty or not a string.
368        """
369        if not isinstance(white_list, (set, list, tuple)):
370            raise TypeError(
371                "white_list must be a set, list, or tuple"
372            )
373
374        normalized = set()
375
376        for entry in white_list:
377
378            if not isinstance(entry, str) or not entry.strip():
379                raise ValueError(
380                    "white_list entries must be non-empty strings"
381                )
382
383            normalized.add(entry.strip())
384
385        self.white_list = normalized
386        return self
387

478    def build(self):
479        """
480        Construct an immutable Parameters instance.
481
482        Resolves unspecified builder values using
483        the defaults defined by Parameters.
484
485        Returns:
486            Parameters:
487                Constructed framework configuration.
488
489        Note:
490            The resulting parameter object is frozen
491            after initialization.
492        """
493        from kdc.parameters import Parameters
494
495        parameters = Parameters(self)
496        parameters._freeze()
497        return parameters

Builder for configuring KDC framework parameters.

ParametersBuilder provides a fluent interface for configuring common KDC communication settings.

Configuration includes: - Client startup and network binding. - Protocol version and receive buffer size. - Compression and encryption. - CRC integrity checking. - Python-to-Java field name translation. - Serialization security white lists. - Agent class registration. - Serialization diagnostics.

Settings not explicitly configured use the defaults defined by Parameters.

Builder methods return the builder instance, allowing multiple configuration options to be chained.

Example: Configure common KDC settings::

    builder = (
        ParametersBuilder()
        .with_auto_start(True)
        .with_compression(True)
        .with_crc(True)
        .with_case_translation(True)
    )

    parameters = builder.build()

Note: Transport-specific parameter builders extend this class with additional configuration options.
