
# KDC Python API Documentation

Official Python API reference for **Kristen Data Comms (KDC)**, developed by Kristen Software LLC.

KDC is a distributed communications framework that enables applications to exchange serialized software Agents across networks. It is designed to support interoperability between Java, JavaScript, and Python applications.

## Online Documentation

**[View the KDC Python API Reference](https://ckozoyed.github.io/kdc-pydoc/)**

The documentation includes:

- Agent and Reply classes
- TCP client communication
- Client configuration and parameter builders
- Connection and message event handling
- Agent serialization
- Optional compression, encryption, and CRC integrity checking

## About This Repository

This repository contains the HTML documentation generated using [pdoc](https://pdoc.dev/) from the KDC Python source code.

The documentation is published automatically through GitHub Pages.

The Python implementation, tests, and documentation source are maintained separately. This repository is intended for publishing the API reference.
